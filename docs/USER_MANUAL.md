# User Manual - Library Management System

## Getting Started
1. Run `python main.py` to start the application.
2. The dashboard will appear as the default screen.

## Navigation Guide
- **Sidebar:** Use the buttons on the left sidebar to access modules.
- **Breadcrumbs:** Click any breadcrumb link at the top to navigate back.
- **Dashboard Tiles:** Click on statistics or quick actions on the Dashboard.

## Keyboard Shortcuts
- `Ctrl + D`: Open Dashboard
- `Ctrl + B`: Open Books view
- `Ctrl + M`: Open Members view
- `Ctrl + I`: Open Issue Book view
- `Ctrl + R`: Open Return Book view
