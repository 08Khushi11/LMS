# Software Requirements Specification (SRS)
## Library Management System (TQM - Q14)

### 1. Introduction
The Library Management System is a desktop application designed to manage books, members, and transactions.

### 2. Functional Requirements
- **FR1:** The system shall allow users to add, view, update, and delete books.
- **FR2:** The system shall allow users to register, view, update, and delete members.
- **FR3:** The system shall manage the issuing and returning of books.
